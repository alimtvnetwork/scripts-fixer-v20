## Where
- `01-ubuntu-installation.md`, `02-fedora-installation.md`, `03-centos-installation.md`
## What
Translate: `apt install bleachbit flameshot uidmap`.
## How

- **Fedora**: `sudo dnf install bleachbit flameshot shadow-utils -y`.
