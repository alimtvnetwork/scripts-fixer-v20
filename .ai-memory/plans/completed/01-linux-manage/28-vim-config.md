# Task 28: Translate Vim Configuration
## Where
- `01-ubuntu-installation.md`, `02-fedora-installation.md`, `03-centos-installation.md`
## What
Translate: `echo "set number" >> ~/.vimrc`, `echo "syntax on" >> ~/.vimrc`, `apt install vim`.
## How
- **Ubuntu**: `sudo apt install vim`.
- **Fedora/CentOS**: `sudo dnf install vim`.
- **All**: Provide the configuration commands to write to `~/.vimrc`.
