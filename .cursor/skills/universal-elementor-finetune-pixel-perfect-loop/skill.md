# Universal Elementor Fine-Tune & Pixel-Perfect Screen Comparison

> **Invocation:** `@[universal-elementor-finetune-pixel-perfect-loop](directory;.agents/skills/universal-elementor-finetune-pixel-perfect-loop)`

## Mission & Purpose
This skill provides authoritative architectural guidance, code navigation, and execution rules for:
1. **Mandatory Dual-Prerequisite Gate:** Confirm learning and memory internalization of the Python Task Automation Prompt and WordPress Actions Prompt (50 steps each) before modifying code.
2. **Target URLs Ingestion Gate:** Operator prompts for original reference URL/slug and target modified Elementor URL/slug.
3. **Multi-Viewport Screen Matrix (`screens.json`):** Standardized coverage across 6–8 viewports (Desktop 4K/Laptop, Tablet Portrait/Landscape, Mobile Landing/Tab/Landscape/Small).
4. **100 to 300 Iteration Continuous Feedback Loop:** Headless screenshot capture, pixel-by-pixel Pillow diffing, difference heatmaps, root-cause diagnosis, targeted CSS/AST adjustments, and browser re-verification until 0% visual gap.
5. **Zero Data Loss Invariant:** Pre-flight draft backups (`<Title> - Backup [Timestamp]`) saved to `backups.json` prior to any AST or postmeta modification.
6. **Screenshot Hygiene & Git Ignore:** Screenshots stored in `screenshots/` and strictly excluded via `.gitignore`; previous turn screenshots purged at iteration $K+1$.
7. **AI Memory & 4-Part RCA Logging:** Record struggle points, root causes, and concrete remediation steps in `.ai-memory/` for future agents.
