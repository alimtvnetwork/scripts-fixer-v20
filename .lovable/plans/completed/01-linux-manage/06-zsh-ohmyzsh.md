# Task 06: Translate ZSH & Oh My Zsh
## Where
- `01-ubuntu-installation.md`, `02-fedora-installation.md`, `03-centos-installation.md`
## What
Translate: `apt install zsh -y`, `chsh -s $(which zsh)`, `wget https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh`.
## How
- **Ubuntu**: `sudo apt install zsh -y`, `chsh -s $(which zsh)`.
- **Fedora**: `sudo dnf install zsh -y`, `chsh -s $(which zsh)`.
- **CentOS**: `sudo yum install zsh -y`, `chsh -s $(which zsh)`.
- **All**: Include the Oh My Zsh wget script installation command.
