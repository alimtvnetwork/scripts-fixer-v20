# Task 24: Translate Download Managers (Aria2, wget, curl)
## Where
- `01-ubuntu-installation.md`, `02-fedora-installation.md`, `03-centos-installation.md`
## What
Translate: `apt-fast install aria2 wget curl`.
## How
- **Ubuntu**: `sudo apt install aria2 wget curl -y`.
- **Fedora**: `sudo dnf install aria2 wget curl -y`.
- **CentOS**: `sudo yum install aria2 wget curl -y`.
