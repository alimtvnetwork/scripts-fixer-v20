# Task 19: Translate DBeaver Community Edition
## Where
- `01-ubuntu-installation.md`, `02-fedora-installation.md`, `03-centos-installation.md`
## What
Translate: `wget https://dbeaver.io/files/dbeaver-ce_latest_amd64.deb`, `sudo dpkg -i`.
## How
- **Ubuntu**: `wget dbeaver-ce_latest_amd64.deb` and `sudo apt install ./dbeaver-ce_latest_amd64.deb`.
- **Fedora/CentOS**: Change URL to `.rpm`, `wget dbeaver-ce_latest_amd64.rpm`, `sudo dnf install ./dbeaver-ce_latest_amd64.rpm`.
