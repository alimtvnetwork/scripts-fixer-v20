# Antigravity Rule: Coding Guidelines

> **Version:** 2.2.0  
> **Status:** Active Rule

1. Functions must be ≤ 8 lines.
2. No nested `if` statements (guard clauses only).
3. Boolean variables must use `is`/`has` prefixes.
4. CODE RED: Always log exact file path + failure reason.
5. Windows Nginx paths must strictly use forward slashes `/`.
