# Universal Email Integration Engine

Canonical reference and master prompt library for universal email integration across any programming language (Python, PowerShell, Bash/Shell, Go, Node.js, C#, PHP, Rust).

## Key Components
- [01-universal-email-integration-prompt.md](file:///d:/work/gitmap/01-prompts/37-universal-email/01-universal-email-integration-prompt.md): Master standalone execution prompt.
- **3-Slot Password Security Architecture**:
  - RSA-2048/4096 OAEP SHA-256 asymmetric slot encryption.
  - Dual-pass Base64 in 3 balanced splits fallback.
- **Provider Connection Matrices**: Gmail, Microsoft Office 365 / Outlook, SendGrid, Mailgun, Amazon SES.
- **Database Schema**: PascalCase SQLite tables for accounts, credentials, queues, and message logs.
